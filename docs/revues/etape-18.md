# Relecture du panel : étape 18 (petites retouches d'interface)

Captures : `docs/revues/etape-18/`. Relecture de Léo (designer d'interface) sur 20 captures ordinateur et téléphone.

| Constat | Retouche |
|---|---|
| Menu : liens publics et espace membre mélangés | Public à gauche ; après un séparateur, Espaces et un bouton « Mon compte » / « Connexion » distinct |
| Téléphone : menu coupé sans indice qu'il défile | Dégradé à droite |
| Titre de page collé à l'en-tête | Plus d'air |
| Carte de France immense | Images limitées en hauteur, centrées, légende centrée |
| Sous-pages en simples liens | Cartes « À lire aussi » |
| Pied de page presque vide | Nom, texte du pied de page, pages hors menu (Confidentialité), puis Boussole |
| Mon compte : bouton sur deux lignes, cartes mêlées | Boutons sur une ligne ; « Gestion de l'association » à part |
| Résumé d'événement trop long | Résumé raccourci |
| Introduction de l'accueil (demande du responsable) | Centrée, en chapeau |
